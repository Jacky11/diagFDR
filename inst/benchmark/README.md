# Benchmarks of the accompanying article

These scripts regenerate the simulations and the spike-in analysis of the DiffPTM article
(in preparation). They are not needed to use the package. Each script is run from the package
folder after `devtools::load_all()` and writes its results under `benchmark/results/` (or the
folder given in its configuration list, described at the top of each script). Running the
complete set takes several days on one core; most scripts are resumable (one result file per
simulated dataset).

| Script | What it computes |
|---|---|
| `run_simulation_v2.R` | Main grid: 540 simulated datasets (3 or 5 samples per condition × 10, 20, 40 % missing values × three shares of values missing at random × three within-sample correlations × 10 seeds); all model forms, with and without single imputation |
| `run_extra_seeds.R` | MSstatsPTM on the remaining seeds of the 20 % missing-value settings; msqrob2PTM with and without robust estimation |
| `run_factorial.R` | Pairing × moderation factorial with one estimator (variants of the limma single model) |
| `run_sensitivity.R` | Unit protein coefficient β ≠ 1, heterogeneous within-sample correlation, summarisation filter |
| `run_sensitivity_complete_pairs.R` | The consensus model on complete pairs on the datasets of `run_sensitivity.R` |
| `run_consensus_mechanism.R` | Why the all-observation consensus fit exceeds the nominal FDR (per-site results by pair completeness) |
| `run_combination.R` | Combining the calls of several model forms (intersection, union, majority) |
| `run_review4_sims.R` | Per-site and consensus models on the main grid; two samples per condition; departures from the simulation model; realistic variance structures; negative correlation (parts selected with `review4_config`) |
| `run_spikein.R` | MSstatsPTM ubiquitin spike-in (MassIVE RMSV000000669): sensitivity on the 40 heavy sites and background rate on light sites |

Inputs of `run_spikein.R` are the MassIVE.quant exports of reanalysis RMSV000000669 (summarised
site and protein intensities, and the published adjusted model), placed in `benchmark/data/`.
Simulated data are generated by `simulate_ptm_features()`; evaluation uses
`evaluate_against_truth()`.
